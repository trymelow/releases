# Melow releases

Installers and auto-update feeds for the [Melow](https://melow.fun) desktop app. This repository holds binaries only;
releases are published by CI.

- Windows: `Melow-Setup-x64.exe`, `Melow-x64.msi`, `Melow-portable-x64.zip`
- macOS: `Melow-arm64.dmg`, `Melow-x64.dmg`
- Linux: `Melow-x86_64.AppImage`, `melow_amd64.deb`, AUR `melow-bin`

Latest: https://github.com/trymelow/releases/releases/latest
