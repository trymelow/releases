# Melow releases

Installers and auto-update feeds for the [Melow](https://melow.fun) desktop and mobile apps. This repository holds
binaries only; releases are published by CI.

- Windows: `Melow-Setup-x64.exe`, `Melow-x64.msi`, `Melow-portable-x64.zip`
- macOS: `Melow-arm64.dmg`, `Melow-x64.dmg`
- Linux: `Melow-x86_64.AppImage`, `melow_amd64.deb`, AUR `melow-bin`
- Android: `Melow.apk`
- iOS: `Melow.ipa`, installed with AltStore or Sideloadly using your own Apple ID

Latest desktop: https://github.com/trymelow/releases/releases/latest

Mobile releases are tagged `mobile-v*`:
https://github.com/trymelow/releases/releases/tag/mobile-v0.2.0
